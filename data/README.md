# Synthetic data and provenance

The manuscript and audited source use no external experimental dataset.
Random Fourier functions and their PDE solutions are generated by the preserved
JAX solvers. No personal, clinical or proprietary observational data was found
in the selected experiment arrays.

Bundled materials comprise the archived manuscript/revision NPZ and CSV
diagnostics, available training curves, five final step-200000 parameter
checkpoints, and small newly generated six-pair example prompts.
The historical 40,000-pair offline pools were generated in memory and are not
stored as files. Generation code and seed splitting are preserved.

`DATASETS.csv` gives path, byte size, SHA-256 and role for each packaged dataset
or checkpoint. `MANIFEST.sha256` can be checked from the repository root:
`sha256sum -c data/MANIFEST.sha256`.
`samples/PROVENANCE.json` distinguishes newly generated release examples from
historical research data.

The original project holds 100 checkpoint snapshots (about 1.9 GB); only five
final checkpoints are bundled. None of the source files individually exceeds
50 MiB or the 100 MiB GitHub limit. The final checkpoints are about 19 MB each.
For publishing the entire training history, use Git LFS or an archival service
such as Zenodo/Figshare and obtain a persistent DOI. No archival deposition or
DOI has been created in this preparation task.
See [GitHub's file-size policy](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

Machine paths in NPZ string metadata were converted to relative provenance
paths; numeric values were not changed. The legacy nested object/pickle NPZ
from corrupted training is excluded because it is not used by the current
manuscript. All bundled arrays load with `allow_pickle=False`.
Notebook outputs and machine metadata were removed.

Redistribution licenses for original data, figures and weights await author
approval. No third-party data or third-party pretrained weights are uploaded.
