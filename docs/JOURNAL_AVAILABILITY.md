# Manuscript-ready availability statements

Anonymous public access was verified on 13 October 2026. The repository HTML/API and representative raw downloads returned HTTP 200; a credential-free Git clone passed all 33 dataset/checkpoint SHA-256 checks and all three integrity tests. See results/verification/public_access_checks.json.

## Data Availability

All experimental data were generated synthetically; no external datasets were used. The archived numerical results, figure assets, final trained model checkpoints and representative synthetic samples are publicly available in the ICON-Spectral-Audit repository at https://github.com/gaozhiweiPHD/ICON-Spectral-Audit. Training datasets were generated in memory; the generation scripts and random-seed configurations are provided. The coverage and limitations of the archived materials are documented in the repository.

## Code Availability

The JAX/Flax code for synthetic data generation, ICON model training and evaluation, Jacobian-based spectral diagnostics and figure generation is publicly available in the ICON-Spectral-Audit repository at https://github.com/gaozhiweiPHD/ICON-Spectral-Audit. Software dependencies, configurations, random seeds, reproduction commands and verified test results are documented in the repository. Original code is released under the MIT license, with third-party license notices retained.
